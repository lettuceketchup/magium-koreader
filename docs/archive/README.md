# Archive — the research & design dossier

This directory is the **historical record** of how `magium-koreader` was
researched, designed, and built. It is kept for provenance and context; it is
**not** needed to install, play, or contribute to the plugin.

Start with the top-level [`README.md`](../../README.md) and
[`CONTRIBUTING.md`](../../CONTRIBUTING.md) instead. The living design documents —
[`../decisions/`](../decisions/) (ADRs) and [`../specs/`](../specs/)
(implementation specs) — stay outside this archive.

## What's here

| Path | What it was |
|---|---|
| [`research-plan.md`](research-plan.md) | The dated running log of the whole project, newest entry last. Still appended to for maintenance work. |
| [`SUMMARY.md`](SUMMARY.md) | The research conclusions, with confidence tags. |
| [`research/`](research/) | The nine research topic docs (`00`–`09`): Magium engine analysis, the `.magium` format, the KOReader platform, constraints, prior art, approach comparison, risks & open questions (all closed), licensing, and the phased roadmap. |
| [`spikes/`](spikes/) | Throwaway feasibility experiments, each with `HYPOTHESIS.md` / code / `FINDING.md`. |
| [`superpowers/`](superpowers/) | Brainstorming design docs and implementation plans from the phase workflow. |

Cross-links inside the spike and plan files may point at pre-archive paths — they
were throwaway working notes and haven't been rewritten.
